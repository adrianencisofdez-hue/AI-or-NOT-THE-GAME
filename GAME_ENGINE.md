# GAME ENGINE

This document describes the definitive gameplay.

- Infinite arcade game.
- No score.
- Only streak.
- Best streak stored in LocalStorage.
- PLAY starts a new run.
- First 3 images easy.
- Afterwards random difficulty.
- AI / REAL completely random.
- Never repeat an image during the same run.
- Wrong answer immediately ends the run.
- Show GAME OVER.
- Show current streak.
- Show best streak.
- Show TRY AGAIN.
- TRY AGAIN starts a completely new run.
- Unlimited images.
- No timers.
- No lives.
- No image counter.
- No score.
