# AI or NOT? THE GAME

## Goal
A fast, addictive web game where players guess whether an image is AI-generated or a real photograph.

## Core Gameplay
- Press PLAY to start.
- Streak starts at 0.
- One random image is displayed.
- Player chooses:
  - AI GENERATED
  - REAL PHOTO
- Correct answer:
  - Increase streak by 1.
  - Load another random unused image.
- Wrong answer:
  - Show GAME OVER.
  - Show current streak.
  - Show best streak.
  - Display TRY AGAIN.

## There must never be:
- Score
- Lives
- Timer
- Image counter

## UI
- Dark background
- Neon style
- Pixel font
- Responsive design
- Mobile first

## Storage
Save the best streak using Local Storage.
