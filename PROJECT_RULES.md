# PROJECT RULES

The following files are considered CORE.

- app/game/page.tsx
- game engine
- game logic
- image randomization
- streak system
- game over system
- try again system
- localStorage
- image database

These systems MUST NEVER be modified unless the user explicitly asks.

UI improvements must NEVER modify gameplay.

Visual changes must NEVER modify game rules.

Never introduce:

- score
- image counters (1/10 etc.)
- lives
- timers
- XP
- levels
- achievements

unless explicitly requested.

Before every future modification you MUST read PROJECT_RULES.md.
